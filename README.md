# 📱 Angular Messaging App

Aplicación Angular para mensajería de texto, lista para usar y conectar con la API de Messangi.

---

## 🚀 Instalación

1. Clona el repositorio o descarga el proyecto.

2. Instala las dependencias necesarias:

```bash
npm install
```

---

## ▶️ Levantar la aplicación

Inicia el servidor de desarrollo con:

```bash
npm run start
```

Abre tu navegador en [http://localhost:4200](http://localhost:4200) para usar la app.
